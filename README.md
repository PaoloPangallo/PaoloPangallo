## 🚀 Selected projects

### [LLM + PDDL Automated Planning](https://github.com/PaoloPangallo/PDDL_LLM)
A generate–validate–refine pipeline that turns structured narrative input into PDDL, validates generated plans with **Fast Downward**, and uses an LLM reflection step for automatic correction.

**Tech:** Python · LangGraph · Ollama · RAG · PDDL · Symbolic AI

### [Graph-Based Scientific Paper Recommendation](https://github.com/PaoloPangallo/Data-Mining-Streamlit)
Scientific-paper recommendation using graph representations, learned node embeddings and bibliographic metadata, with an interactive Streamlit interface.

**Tech:** PyTorch · GNNs · scikit-learn · Streamlit · OpenAlex · NetworkX

### [Electric Cable Instance Segmentation](https://github.com/PaoloPangallo/Cable-Instance_Segmentation)
Transformer-based instance segmentation for thin electrical cables in aerial imagery, including geometry-aware post-processing and evaluation.

**Tech:** PyTorch · Computer Vision · RF-DETR · Vision Transformers · PCA

### [Multi-Agent RL for Traffic Signal Control](https://github.com/PaoloPangallo/SUMO_MARL)
Multi-agent reinforcement learning for traffic-signal optimization in SUMO, comparing independent agents, CTDE approaches and attention-based coordination.

**Tech:** PyTorch · SUMO · TraCI · RLlib · MARL · Graph Attention
